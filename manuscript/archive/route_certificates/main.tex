\begin{abstract}
Reverse-mode differentiation normally retains or reconstructs forward state
because local pullbacks depend on the values that produced them.  Hard routing
admits a narrower alternative: a forward decision can identify the complete
selected pullback.  We give a sufficient condition under which a finite
executed graph emits an exact differentiation certificate.  Given an output
cotangent, static graph state, unchanged parameters, and explicitly declared
boundary data, the certificate determines state and parameter
vector--Jacobian products under the declared derivative selection, without
unrecorded activations or forward recomputation.  Additive max/min-plus maps
satisfy the condition: winner
indices route both state cotangents and additive-parameter cotangents by
gather, scatter, and addition.  The result composes through fan-out, residual
branches, shared parameters, and finite recurrent unrollings, with an explicit
tie contract and a conditional coding lower bound.  It does not cover dense parameter
outer products, smooth attention, ordinary normalization, the loss boundary,
or the optimizer.  Thirty-eight core theorem tests and 37 integration,
serialization, and benchmark-hardening tests pass in the current TikiTorch
worktree.  On three hard-routed MorphSSM configurations, a portable certificate
is 1.97--2.96$\times$ smaller than checkpoint-retained state under a common
supplied-cotangent boundary.  Under the current loss-inclusive replay boundary,
which retains logits and targets on both sides, the ratio is
1.69--2.79$\times$.  These are retained-state measurements, not process peak,
memory traffic, latency, or energy results.  Forward traces are therefore
operator-specific adjoint tapes: neither a new gradient rule nor a generic
activation-free learner.
\end{abstract}

\noindent\textbf{Keywords:} reverse-mode differentiation; hard routing;
tropical networks; adjoint tape; activation memory; morphological networks

\section{Introduction}

Reverse-mode automatic differentiation (AD) evaluates a vector--Jacobian
product by traversing an executed graph backwards.  Its local transpose
actions often depend on primal values, so frameworks retain a tape, recompute
values from checkpoints, or recover values from reversible structure
\citep{giering1998recipes,griewank2000revolve,chen2016sublinear,gomez2017reversible}.
These strategies expose a basic systems question: what is the smallest forward
record that determines the requested pullback?

The record can be smaller than the forward value.  Pooling switches and
compressed backward-state methods exploit this observation approximately or
for particular operators \citep{zeiler2014visualizing,jain2018gist,novikov2023fewbit}.
For a hard max/min choice, it can be exact.  Once a branch wins, its discrete
route may select every nonzero and every numerical coefficient in the local
Jacobian.  In an additive max-plus parameterization, the same route also
selects the parameter derivative.  The values that competed need not be
retained for that local action.

We develop this observation as an operator contract and compose it across an
executed graph.  The contribution has three parts:

\begin{enumerate}[leftmargin=1.5em]
  \item A trace-sufficiency criterion for exact state and parameter VJPs under
  a declared derivative selection, with a reverse-topological composition
  theorem, operator-declared tie rules, finite recurrence, and a conditional
  coding bound.
  \item An executable certificate format and explicit operator boundary.  The
  accepted hard core is generated by gather, scatter, copy, sign change, fixed
  address shifts, and addition; unsupported value-dependent operations remain
  visible.
  \item Exactness and retained-state measurements on a reference residual DAG
  and TikiTorch MorphSSM configurations.  The current positive result is a
  representation result.  Optimized latency, process peak, and traffic remain
  preregistered decision gates.
\end{enumerate}

Once the local trace-sufficiency contract is assumed, the graph theorem is an
intentionally direct chain-rule argument.  The contribution does not rest on
that induction alone.  It rests on identifying concrete state and parameter
pullbacks that satisfy the contract, representing their complete auxiliary
state in a typed portable tape, exposing counterexamples and boundary costs,
and testing the resulting replay against framework differentiation.

Three distinctions are central.  First, the reverse recursion is ordinary
reverse accumulation after the forward route is fixed; we do not propose a new
gradient.  Second, trace sufficiency is operator- and derivative-specific;
hard routing around a dense expert does not make the expert's weight gradient
route-sufficient.  Third, the result does not make an entire model
``activation-free.''  The output cotangent, loss state, continuous boundaries,
and optimizer state must be supplied, retained, recomputed, or separately
certified.

\section{Trace-sufficient reverse differentiation}

Let an executed model be a finite directed acyclic graph with nodes
\begin{equation}
 z_v=f_v\big((z_u)_{u\in\mathrm{pa}(v)},\theta_v\big).
\end{equation}
A finite recurrent window is represented by its unrolled graph.  Node $v$
emits a certificate $c_v=(r_v,a_v)$, containing discrete route data $r_v$ and
any declared auxiliary data $a_v$.  Static topology, shapes, and unchanged
parameters are available to the reverse program.  A local $\theta_v$ may alias
a shared global parameter; contributions from every alias are accumulated into
that parameter's global cotangent.

For a declared derivative selection $D_v$ at the realized forward point,
$c_v$ is \emph{state trace-sufficient} when, for every incoming cotangent $q$,
there exists an evaluator
\begin{equation}
 P_{vu}(q;c_v,\theta_v,\mathrm{static})
 =\big(D_v^{z_u}f_v\big)^Tq
\end{equation}
that uses no unrecorded forward activation.  It is \emph{parameter
trace-sufficient} when an analogous evaluator $Q_v$ returns
$(D_v^{\theta_v}f_v)^Tq$.

\begin{theorem}[Trace-sufficient reverse differentiation]
If every executed node of a finite DAG is state trace-sufficient for a common
declared derivative selection, and every node whose parameter derivative is
requested is parameter trace-sufficient, then the supplied output cotangent
and certificate collection $\cert=(c_v)_v$ determine the corresponding
selected reverse-mode state and parameter VJPs exactly.
\end{theorem}

The proof is a reverse-topological induction.  At node $v$, all downstream
paths have accumulated into $\bar z_v$.  Applying $P_{vu}$ to every parent and
$Q_v$ to the local parameters, then adding contributions, is precisely the
chain rule.  Addition handles fan-out, residual paths, repeated edges, and
shared parameters.  The full proof is in Supplementary Section~\ref{supp:proof}.

The theorem specializes reverse mode; it does not replace it.  Reverse work is
the sum of local transpose-action costs.  Certificate storage is
$\sum_v |c_v|$ plus field metadata, padding, declared boundary values, and any
optimizer state.  A useful implementation must report each of those quantities
rather than relabeling all training memory as ``routes.''

\subsection{Additive max/min-plus operators}

For
\begin{equation}
 y_j=\max_i(x_i+w_{ji})+b_j,
\end{equation}
let an exact value tie select the smallest input index.  With winner
$i_j^\star$,
\begin{equation}
 \frac{\partial y_j}{\partial x_i}=\mathbf{1}[i=i_j^\star],\qquad
 \frac{\partial y_j}{\partial w_{ji}}=\mathbf{1}[i=i_j^\star],\qquad
 \frac{\partial y_j}{\partial b_j}=1.
\end{equation}
The state VJP is a scatter-add.  The selected additive weight receives a routed
copy of the output cotangent, and the bias receives a reduction.  Min-plus
changes the comparison but not this selected derivative.  Morphological
convolution adds a static address map; overlap and parameter sharing add
contributions \citep{franchi2020morphological,groenendijk2023geometric}.

This joint state-and-parameter result depends on the additive parameterization.
For $y=Wx$, the state VJP can use the unchanged weight, but the exact weight
VJP is $qx^T$ and therefore depends on the activation $x$.  A dense or dyadic
linear map does not become parameter trace-sufficient merely because its state
action is sparse or shift-add.

\section{Ties, active sets, and certificate size}

At a tie, an extremum has no unique classical derivative.  The reference
operators select the smallest candidate index and gather the forward value
through that same index, so framework AD and explicit reverse choose the same
branch derivative for those operators.  This rule is not silently transferred
to another model implementation.  The MorphSSM bridge records the route emitted
by the model and guarantees replay of that declared route; equivalence to
framework AD at an exact tie additionally requires the model primitive and AD
backend to share the same selection.  Pairwise maximum, backend \code{topk},
and an independently cached comparison can otherwise disagree.

If the winning score exceeds the runner-up by $\gamma>0$ and every candidate
score changes by at most $\epsilon$, then the winner is unchanged whenever
$2\epsilon<\gamma$.  In 2,353 sampled cases satisfying this conservative
certificate, no route changed.  Whenever the route remained fixed, frozen and
recomputed VJPs were bit-identical.  Route flips and VJP discrepancy increased
together as perturbations grew.  This gives a checkable local active-set
domain; it is not a proof about route-changing iterative inference.

There is also a conditional information bound.  Hold all reverse-available
static state fixed.  If $M$ local selected Jacobian classes are distinguishable
by some cotangent, an exact one-forward, no-recomputation evaluator must encode
them injectively.  A fixed-width record needs at least
$\lceil\log_2M\rceil$ bits in the worst case; a uniquely decodable
variable-length record needs expected length at least the route entropy.  This
is not a universal lower bound on training memory: recomputation, reversible
reconstruction, correlations, or another sufficient statistic change the
problem.

\section{Certificate implementation in TikiTorch}

The TikiTorch research implementation records typed tensor fields with a name,
shape, cardinality, bit width, and bit offset.  A cardinality $M$ receives
$\lceil\log_2M\rceil$ bits; fields are bit-packed without byte alignment.  A
versioned directory precedes the payload in the portable representation.  The
artifact reports three noninterchangeable quantities: logical field bits,
payload bytes, and serialized bytes including the directory.  A fixed-capacity
ring permits bounded chronological storage for finite recurrent windows.

For the hard MorphSSM configuration, the internal record includes
morphological-convolution winners, additive projection winners, recurrent
carry gates when present, dropout masks during training, top-$k$ winners, and
selected normalization exponents.  Token identifiers address embedding rows.
The theorem takes an output cotangent as supplied boundary data.  The current
MorphSSM replay API instead takes logits and targets and constructs that
cotangent through a softmax loss boundary before replaying the hard trunk.
Those tensors and that smooth boundary are not part of the certificate theorem;
they are retained and counted in the loss-inclusive comparison below.  Smooth
attention paths, dense projections, ordinary normalization, unsupported grouped
convolution, and non-unit residual scales are outside the validated certificate
path.

The existing TikiTorch \code{RouteCertificate} API exposes target-free route
support and multiplicity for the hard trunk.  The paper artifact additionally
requires the complete replay fields and stable packed serialization described
above.  Release is gated on consolidating those two layers behind one public,
versioned certificate interface rather than treating a support inventory as a
whole-model VJP certificate.

\section{Evaluation}

We ask four separate questions: (1) does replay return the declared selected
VJP, (2) how many bytes are retained, (3) what recomputation and memory traffic
are induced, and (4) what is the compiled full-cycle latency?  A method must
pass exactness before its systems result is included.

\subsection{Correctness and reference-DAG audit}

Five predeclared core groups contain 38 tests.  Float64 randomized fixtures
compare explicit state and parameter VJPs with framework AD and central finite
differences away from ties.  Structured tests cover max/min, top-$k$,
overlapping convolution, several outputs selecting one input, residual
branches, concatenation, shared-parent fan-out, composition, exact ties,
one-unit-in-the-last-place perturbations, packed round trips, and the dense
parameter-gradient counterexample.  All 38 pass under the recorded reference
environment.  A further 37 tests exercise migrated reverse primitives,
MorphSSM tape parity, package serialization, and benchmark durability.  The
combined focused suite contains 75 passing tests in the current worktree; the
historical 38-test record remains the provenance anchor for the core result.

On a matched additive hard-routed residual DAG, all methods share parameters,
input, supplied output cotangent, precision, update order, and SGD schedule.
The maximum parameter-gradient discrepancy from eager autograd is
$4.77\times10^{-7}$; after five SGD steps the maximum parameter discrepancy is
$2.98\times10^{-8}$ in FP32.  Serialized certificates are 5.0--6.3$\times$
smaller than checkpoint nonparameter saved state in the small CPU grid.  The
Python serializer is 3.3--3.8$\times$ slower than eager autograd, so this
microbenchmark supports exactness and representation only.

\section{Related work}

The result is closest to adjoint control tapes, checkpointing, compressed
backward state, pooling switches, sparse Jacobian methods, and morphological
provenance \citep{giering1998recipes,griewank2000revolve,coleman1998sparse,zeiler2014visualizing,jain2018gist,novikov2023fewbit,groenendijk2023geometric}.
It differs from general activation compression by asking whether a discrete
record is a sufficient statistic for an exact requested transpose action.
It differs from checkpointing and reversible networks by retaining selected
derivative state instead of reconstructing a primal state.

Tropical and morphological networks make the criterion concrete because their
hard additive extrema have route-selected unit derivatives
\citep{zhang2018tropical,franchi2020morphological}.  Sparse expert routing and
sparse training accelerators also exploit selected structure
\citep{shazeer2017moe,parashar2017scnn,yang2020procrustes}, but an expert index
does not determine a dense expert's parameter VJP.  Nonsmooth AD further
clarifies that tie selection and program semantics must be explicit
\citep{bolte2023nonsmooth}.

Predictive-coding schedules can reproduce backpropagation or reverse
differentiation under prescribed conditions
\citep{song2020exactpc,salvatori2022reverse,millidge2022arbitrary}.  When a
``cascade'' and a custom route reverse use the same fixed routes, reductions,
and reverse-topological recurrence, they are the same selected VJP computation.
We therefore do not count them as distinct learning rules or comparison arms.

\section{Limitations and claim boundary}

The theorem is exact but conditional.  It applies to a finite executed graph,
a declared derivative selection, unchanged reverse-available parameters, and
an explicitly supplied output cotangent.  Routes may cease to be valid after
an active-set change.  Route indices alone do not cover auxiliary masks,
selected scales, token addresses, or continuous boundary values.

The current measurements establish exact replay for tested operators and a
boundary-matched retained-state representation advantage in three MorphSSM
configurations: 1.97--2.96$\times$ at a common supplied-cotangent boundary and
1.69--2.79$\times$ for the current loss-inclusive portable replay.
They do not establish a generic checkpoint replacement, an optimized latency
win, a process-peak-memory win, lower memory traffic, deployment-scale energy
benefit, or whole-model activation elimination.  The hardware execution of
hard-routed learning is intentionally reported in a separate work; it is not
evidence for the software-system comparisons left open here.

\section{Conclusion}

A hard forward route can be an exact differentiation certificate when it
selects every coefficient required by the requested local transpose actions.
For additive max/min-plus operators, the winner determines both state routing
and the selected additive-parameter derivative.  These certificates compose
through an executed graph by ordinary reverse accumulation.  TikiTorch's
current evidence shows exact replay and a boundary-matched retained-state
reduction over a registered checkpoint comparator on three MorphSSM
configurations: 1.97--2.96$\times$ for portable certificates at a supplied-
cotangent boundary, and 1.69--2.79$\times$ when the current replay retains its
loss boundary.  The remaining question is a systems question: whether a
compiled certificate implementation converts that representation advantage
into lower peak memory or traffic without losing full-cycle latency.  Until
that comparison is complete, the contribution is deliberately narrow: an
operator-specific exact adjoint tape, not a new gradient and not a generic
activation-free learner.
