# Tutorials

TikiTorch has two complementary kinds of learning material.

## Notebook tutorials

The six generated notebooks build concepts progressively and include plots and small
experiments. Start with the [notebook index](../guide/notebooks.md) if you want a guided
introduction to tropical algebra, vision, sequence models, geometry, or algorithmic
applications.

## Runnable examples

The scripts under `examples/` are short, command-line programs intended for copying
into a project. Use the [examples index](examples.md) when you want one isolated task,
such as backend dispatch, a closure ablation, or a CPU-safe smoke run.

## What tutorials establish

Tutorial output demonstrates a particular local configuration; it is not automatically
a benchmark or hardware result. Quantitative research claims are governed by the
[research evidence boundary](../research/index.md), where configurations, artifacts,
and remaining gates are tracked separately from educational examples.
