# Deprecated — superseded ICML two-column version

`main.tex`/`main.pdf` is the earlier ICML-format manuscript, superseded by the
Nature-format `../main_nature.tex` (canonical). The ICML template files
(`icml2025.sty`, `icml2025.bst`, `algorithm.sty`, `algorithmic.sty`,
`fancyhdr.sty`, `forloop.sty`, `icml2025/`) live here too.

Shared resources stayed in the parent dir: `references.bib`, `neuro_refs.bib`,
`figs/`, and the figure scripts. `main.tex` references those by relative path, so
it will not rebuild from here without path fixes — it is frozen; `main.pdf` is the
preserved artifact.
